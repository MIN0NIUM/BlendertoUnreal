### N-1. 再インポート時の設定保持（T-7）— UE 側実装 ★本命

**なぜ**: 今は 2 回目のインポートで UE 側の手修正（Nanite / コリジョン / ライトマップ /
マテリアル割当 / ソケット / Build Settings）が消えうる。量産では致命的。

**設計**

- 新規モジュール `tools/ue_plugin/onepochi_ue/reimport.py`
  - **純粋ロジック**（`unreal` 非依存・単体テスト可）
    - `resolve_policy(manifest, asset)` → `{"mode": ..., "override": [...]}`（アセット側がマニフェスト側を上書き）
    - `plan_categories(policy, existed)` → `{"preserve": [...], "apply": [...]}`
      - `mode = overwriteAll` または初回（`existed = False`）→ 全カテゴリ `apply`
      - `mode = preserveSettings` → `override` に挙がったものだけ `apply`、残りは `preserve`
  - **UE 依存**（`postprocess` のヘルパを使う）
    - `capture(mesh, sink)` → インポート前の設定スナップショット
    - `restore(mesh, snapshot, categories, sink)` → インポート後に復元
- カテゴリは**スキーマの `override` の enum と一致させる**:
  `nanite` / `lod` / `collision` / `lightmap` / `materials` / `sockets` / `buildSettings`
- `importer.import_static_mesh_asset()` の流れを
  **「既存なら capture → インポート → apply（applyカテゴリのみ）→ restore（preserveカテゴリ）」**にする
- `postprocess.apply_static_mesh(mesh, asset, sink, categories=None)` に
  **適用カテゴリの絞り込みを追加**（既定は従来どおり全適用 = 後方互換）
- レポートに `entry["reimport"]` を追加（`policy` / `preserved` / `applied` / `snapshot` / `restored`）

**DoD**

- [x] `tools/ue_plugin/tests/test_reimport.py` の単体テストが通る（`unreal` 不要）
- [x] 既存テスト 235 件が**1件も壊れない**

### N-3 の API プローブ結果（UE 5.8.3 実測 / `docs/tmp/lod_probe.json` / `lod_sig.json`）

`unreal.get_editor_subsystem(unreal.StaticMeshEditorSubsystem)` は **RC / GUI で取得できる**
（commandlet では `None` / [docs/99](99_作業ルール.md) P-5）。使えるメソッド:

| API | シグネチャ | 用途 |
|---|---|---|
| `import_lod` | `(base_static_mesh, lod_index, source_filename) -> int32` | **LOD ごとの FBX を読み込む本命** |
| `set_lod_screen_sizes` | `(static_mesh, screen_sizes: Array[float]) -> bool` | `screenSize` の適用 |
| `get_lod_screen_sizes` | `(static_mesh) -> Array[float]` | 実測 |
| `set_lods` | `(static_mesh, reduction_options: StaticMeshReductionOptions) -> int32` | `mode = auto` |
| `set_lod_from_static_mesh` | `(dst, dst_lod, src, src_lod, reuse_slots) -> int32` | 別メッシュから LOD を作る |
| `get_lod_count` / `remove_lods` | `(static_mesh) -> int32` / `-> bool` | 実測 / LOD0 以外の削除 |
| `set_lod_build_settings` | `(static_mesh, lod_index, build_options) -> None` | **void**（P-18 に注意） |

- `unreal.StaticMeshReductionOptions`: `reduction_settings` / `auto_compute_lod_screen_size`
- `unreal.StaticMeshReductionSettings`: `percent_triangles` / `screen_size`
- `unreal.StaticMesh`: `get_num_lods()` / `get_num_triangles(lod)` / `set_num_source_models(n)` /
  `is_lod_screen_size_auto_computed()`（**`get_lod_group` / `set_lod_group` は無い**）
- **Interchange 側にも LOD 設定がある**（今回は使わないが記録）:
  `InterchangeGenericCommonMeshesProperties.import_lods`（`bake_meshes` が ON のときだけ有効）/
  `InterchangeGenericMeshPipeline.lod_group` / `lod_screen_sizes` / `auto_compute_lod_screen_sizes`
