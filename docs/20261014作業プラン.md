## 9. 守ること（[CLAUDE.md](../CLAUDE.md) / [docs/99](99_作業ルール.md)）

- **Git 操作はしない**（`git init` / `commit` / `push` / `gh pr create`）。`.gitignore` と CI の配置は**案を書くだけ**
- **ユーザーが開いている Blender セッションを変更・保存しない**。`samples/blender/11_static_texture/11_static_texture.blend` は**読み取りのみ**。新しいサンプルは**別名で自動生成**する（既存の `.blend` に触らない）
- **UE エディタを終了させない**。UE 起動中は必ず `--via-rc`（P-16）。Git Bash から UE パスを渡すときは `MSYS_NO_PATHCONV=1`（P-4）
- **同じタスクで 3 回失敗したら中断**し、原因調査をサブエージェントに投げる（テキストベースのみ / スクリーンショット禁止）
- **1KB を超える Markdown / JSON は `Write` で書く**（P-1）
- UE 5.8 固有の API は**推測で断定しない**。未検証は「要検証」と明記する
- マニフェスト構造を変えたら `schema/onepochi_manifest.schema.json` も同時に更新する（`SCHEMA_VERSION` / `RULESET_VERSION` / `SUPPORTED_SCHEMA_VERSION` の 3 点同期）
- **新しい検証ルール・比較項目を足したら、実サンプルで発火することと `core/verify.py` の `CONDITIONAL` への登録を確認する**（P-30 / K-8。前回 `lodTriangleCounts` が未登録のまま「緑」に見えていた）
- UI 文言・エラーメッセージは日本語のみ
